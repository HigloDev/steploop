# 循阶 · Steploop

Android 爬楼训练应用：多轮训练、实际楼层确认、成绩回顾和本地数据导出，无需注册账号。

## 发布状态

第一版 **1.0.4 公开试用候选正在准备，尚未开放下载**。仓库目前只提供项目主页；完整源码快照和 APK 暂存在维护者可见的 Release 草稿中，尚未提交到公开代码树。

本地已通过 483 项自动化测试、TypeScript、Expo Doctor 21/21，以及全新模拟器首次安装、手动零层保存、冷重启后查看记录。模拟器结果不代表真实爬楼准确率或手机锁屏连续性已经验证。

公开下载前仍需完成真实训练验收，并确认预录语音素材的分发依据。全自动和锁屏能力仍是试验功能。

## 第一版范围

- Android 7.0+，推荐带气压计的 ARM64 手机；不提供 iOS 包。
- 手动、自动与全自动模式，允许人工确认实际楼层。
- 多轮训练、语音反馈、成果动画、记录、分享和备份。
- 数据保存在本机。候选包不嵌入维护者的地图凭据，可无地图开练。
- 明细分别保留最近 100 条训练及旧单轮记录，更早保留汇总统计；原始运动数据需单独导出。

发布后，安装包将出现在 [Releases](https://github.com/HigloDev/steploop/releases)。GitHub 自动生成的 Source code ZIP 不是 Android 安装包。

早期内部版和公开候选签名不同，请勿卸载已有应用来强行换装，以免丢失本地数据。
