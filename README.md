# 循阶 · 每一步向上，每一层都算数

循阶是一款本地保存成绩的 Android 爬楼训练应用。1.1.3 提供完整浅深两套界面、楼层震动、实时运动指标、盖楼结算与周成果分享。

[下载 Android 1.1.3 公开试用版](https://github.com/HigloDev/steploop/releases/tag/v1.1.3-preview.1) · [下载网页](https://higlodev.github.io/steploop/) · [使用与备份](docs/USER_GUIDE.md) · [构建说明](docs/BUILDING.md) · [本版说明](docs/RELEASE_1.1.3.md)

## 本版变化

- 起始楼层在负一楼与一楼之间跳过 0；旧楼栋读取时兼容无效起始层，不重写历史成绩。
- 每到新楼层提供震动提示，主要操作也有反馈；设置可关闭或试听。
- 标定与爬楼页面重新排布，同时显示步数、每分钟楼层、估算热量与上升高度，适配长屏与大字体。
- 成绩保存成功后播放盖楼动画与原创结算铃声；历史成绩和设置预览不会新增训练记录。
- 点击首页周累计查看高度完成情况与 37 种高度参照；独立周分享页提供两款海报、保存、分享和复制文案。
- 全部主要页面、弹层、训练状态分别使用浅色与深色主题。

界面证据：[浅深主题图册](docs/qa/theme-pair-20261010/index.html) · [本次 26 组原生对照、动画录像与铃声](docs/qa/xiaomi14-improvements-20261010/index.html) · [本次验收说明](docs/qa/xiaomi14-improvements-20261010/AUDIT.md)。图册采用合成演示数据，可下载源码后以本地静态服务器打开。

## 安装与升级

下载 Release 中的 `steploop-1.1.3-android.apk`，支持 Android 7.0 及以上、ARM64 和 x86_64。公开包沿用 1.0.5 / 1.0.7 / 1.1.2 的公开签名，可覆盖安装。更新前先在设置里保存备份。内部版使用另一证书，需要匹配证书的内部更新包；遇到签名不匹配时保留原应用和数据，不卸载、不清除数据。

首次使用新楼栋时逐层标定，保存后下次可从首页选择该楼栋。使用步骤、震动和音效设置见 [使用说明](docs/USER_GUIDE.md)。

## 试用范围

自动计层仍是试验能力。源码测试、原生界面和升级检查不代表真实爬楼准确率，不保证所有手机在锁屏、省电或音频中断时持续采样。热量为估算值；参照物的高度口径见 [说明](docs/HEIGHT_REFERENCES_20261010.md)，山峰海拔只作高度对照，不代表实际登顶。云同步、排行、社交和 iOS 不在本次试用范围内。

训练明细和旧单轮明细分别保留最近 100 条，更早记录保留汇总。普通备份包含路线、保留成绩与归档统计，不包含全部原始运动文件、语音日志、偏好或进行中恢复点。公开包不包含维护者的地图凭据，地图不可用时可手动填写信息。

本仓库使用 Expo SDK 57。源码不包含个人备份、原始手机截图、运动记录、地图凭据或签名密钥。预录语音由本机 Qwen3-TTS 官方预置音色生成，许可见仓库及 Release 附件。结算铃声为本项目原创合成音频。

通过 [Issues](https://github.com/HigloDev/steploop/issues) 提供版本、手机型号、Android 版本、是否锁屏和复现步骤；请勿公开上传完整备份、位置或密钥。
