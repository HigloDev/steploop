# 循阶 · 每一步向上，每一层都算数

循阶是一款本地保存成绩的 Android 爬楼训练应用。1.1.2 采用黑橙视觉、新图标与楼栋流程：首页开始 → 第一轮逐层标定 → 保存楼栋 → 下次自动计层。

[下载 Android 1.1.2 公开试用版](https://github.com/HigloDev/steploop/releases/tag/v1.1.2-preview.1) · [使用与备份](docs/USER_GUIDE.md) · [构建说明](docs/BUILDING.md) · [本版说明](docs/RELEASE_1.1.2.md)

## 本版变化

- 完整实施 1.1.2 页面视觉，统一布局、原生弹层、图标和黑橙品牌 logo。
- 首页提供 37 种高度参照，从足球球门到珠峰 8848.86 米，清单展示进度和下一目标。
- 训练记录图标按实际累计完成层数分为 7 档，修改成绩后同步变化，精确层数仍显示在正文中。
- 改善小屏、大字体和浅色主题下的布局，保留原有记录格式。

设计和实际 Android 画面：[设计图册](docs/visual-redraw-1.1.2-20261010/index.html) · [全页面审计](docs/qa/ui-audit-20261010/index.html) · [高度参照与记录图标](docs/qa/height-references-20261010/index.html)。HTML 图册可下载源码后用本地静态服务器打开。参照物的来源与高度口径见 [说明](docs/HEIGHT_REFERENCES_20261010.md)。山峰海拔只作高度对照，不代表实际登顶。

## 安装与升级

下载 Release 中的 `steploop-1.1.2-android.apk`，支持 Android 7.0 及以上、ARM64 和 x86_64。本版沿用 1.0.5 / 1.0.7 公开版签名，可覆盖安装；更新前先在旧应用设置中保存备份。个人内部版采用另一证书，应使用对应内部升级包，不要为签名不匹配而卸载或清除数据。

打开循阶后，点击「开始爬楼」。第一次使用新楼栋时，按页面提示逐层标定；保存后在首页选择该楼栋训练。完整步骤见 [使用说明](docs/USER_GUIDE.md)。

## 试用范围

自动计层仍是试验能力。原生界面、模拟器测试和数据保存检查不代表真实爬楼准确率，也不保证所有手机在锁屏、省电或音频中断时持续采样。热量为估算值。云同步、排行、社交和 iOS 不在本次试用范围内。

训练明细和旧单轮明细分别保留最近 100 条，更早记录保留汇总。普通备份包含路线、保留的成绩与归档统计，不包含全部原始运动文件、语音日志、偏好或进行中恢复点；原始运动数据需另行导出。公开包不含维护者的地图凭据，地图不可用时可手动填写信息。

本仓库使用 Expo SDK 57。依赖、构建和签名按 [构建说明](docs/BUILDING.md) 操作。源码不包含个人备份、原始手机截图、运动记录、地图凭据或签名密钥。固定语音由本机 Qwen3-TTS 官方预置音色生成，许可见仓库及 Release 附件。

通过 [Issues](https://github.com/HigloDev/steploop/issues) 提供版本、手机型号、Android 版本、是否锁屏和复现步骤；请勿公开上传完整备份、位置或密钥。
