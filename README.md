## 皮肤系统

当前源码基于1.1.7综合候选`9c7eed9`，包含钴蓝晴空、荧光夜行、松风山岚、紫电幽光、绯焰流光、晴金跃动、樱粉和弦共7套可选皮肤及独立明暗选择。六套图形皮肤均接入Logo、场景插画和完成图案，原版保留原标志。入口为“设置 → 皮肤与外观”，选择立即生效并保存。当前仍有9张素材的清晰度限制；整体视觉验收保持受限，不因本次手机启动与页面检查而关闭。

后续皮肤统一按 [建设索引](docs/skins/README.md)、[机器目录](docs/skins/registry.json) 和 [建设规范](docs/skins/CONSTRUCTION.md) 开发，覆盖训练／教练／记录／设置四个一级入口及深页。当前检查见 [图形版验证记录](docs/skins/GRAPHICS_VALIDATION.md)，早期配色证据保留在 [旧图册](docs/skins/preview.html)。本次随1.1.7公开试用APK交付。

## 安装与升级

下载 Release 中的 `steploop-1.1.7-android.apk`，支持 Android 7.0 及以上、ARM64 和 x86_64。公开包沿用既有公开签名，可覆盖旧公开版安装。更新前先在设置里保存备份，升级后重新导出一份包含楼栋模板的新备份。内部版使用另一证书，需要匹配证书的内部更新包；遇到签名不匹配时保留原应用和数据，不卸载、不清除数据。

首次使用新楼栋时逐层标定，保存后下次可从首页选择该楼栋。使用步骤、震动和音效设置见 [使用说明](docs/USER_GUIDE.md)。

## 试用范围

自动计层仍是试验能力。源码测试、原生界面和升级检查不代表真实爬楼准确率，不保证所有手机在锁屏、省电或音频中断时持续采样。热量为估算值；参照物的高度口径见 [说明](docs/HEIGHT_REFERENCES_20261010.md)，山峰海拔只作高度对照，不代表实际登顶。云同步、排行、社交和 iOS 不在本次试用范围内。

训练明细和旧单轮明细分别保留最近 100 条，更早记录保留汇总。1.1.5 普通备份包含楼栋模板、旧路线、保留成绩与归档统计，不包含全部原始运动文件、语音日志、偏好或进行中恢复点。公开包不包含维护者的地图凭据，地图不可用时可手动填写信息。

本仓库使用 Expo SDK 57。源码不包含个人备份、原始手机截图、运动记录、地图凭据或签名密钥。预录语音由本机 Qwen3-TTS 官方预置音色生成，许可见仓库及 Release 附件。结算铃声为本项目原创合成音频。

通过 [Issues](https://github.com/HigloDev/steploop/issues) 提供版本、手机型号、Android 版本、是否锁屏和复现步骤；请勿公开上传完整备份、位置或密钥。
