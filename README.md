# 循阶 · 每一步向上，每一层都算数

我把每天爬的楼，做成了一个 APP。

它叫「循阶」：一轮轮记录爬楼，停稳后确认实际楼层，训练中有语音反馈，结束后把成果“盖成楼”，还能回看记录、生成成绩海报。想让普通的一次爬楼，也留下看得见的进步。

**[查看宣传与下载页面](https://higlodev.github.io/steploop/) · [下载 Android 1.0.7 试用版](https://github.com/HigloDev/steploop/releases/download/v1.0.7-preview.1/steploop-1.0.7-android.apk) · [版本说明与校验表](https://github.com/HigloDev/steploop/releases/tag/v1.0.7-preview.1)**

这是面向愿意反馈问题的用户开放的 **Android 试用版（Pre-release）**。真实爬楼识别、锁屏连续采样、耗电及音频中断仍在验证。1.0.7 先带手机“熟悉路线”，检查通过后再开始正式爬楼；这不保证所有人和所有手机都能准确识别。

## 可以体验什么

- **一条主线**：添加或导入路线 → 熟悉路线 → 检查是否认对 → 爬楼 → 查看成绩。保留定位和名称建议，也可手动填写。
- **路线分享**：分享路线文件，导入前预览，同名另存；不分享个人训练成绩。收到的人需用自己的手机完成检查。
- **自己确认楼层**：停稳后确认实际到达楼层，例如 1 楼到 15 楼，实际爬升为 14 层。
- **四种离线音色**：两种男声、两种女声，可选择与试听；无需在手机运行 AI 模型。
- **成果回顾**：盖楼动画、训练记录与趋势、可隐藏地点和身份信息的成绩海报。
- **本地数据**：无需注册账户，数据保存在手机上；支持成绩备份、CSV 和原始运动 JSONL 导出。

## 下载与第一次使用

1. 点击上方 **下载 Android 1.0.7 试用版**，取得 `.apk` 文件。GitHub 自动生成的 Source code ZIP 是源码，不是安装包。
2. 适用于 Android 7.0+ 的 ARM64 手机，推荐有气压计的设备；目前没有 iPhone 安装包。
3. 按系统提示允许当前浏览器或文件管理器安装应用，安装后打开循阶。
4. 在“我的路线”中添加或导入路线。新路线先逐层走两遍，再检查逐层和正常完整爬楼；有电梯时还需检查电梯上下，最后检查平地和休息。按页面提示逐步完成，不必一次做完。
5. 熟悉时固定携带位置，保持前台和屏幕点亮，到平台停稳后再点实际楼层。检查通过后开始正式爬楼，保存后在记录页查看成绩。

**更新前先备份**：本次公开包沿用 1.0.5 公开版的发布签名，可直接覆盖升级。早期个人内部版证书不同，请使用对应内部升级包，不要为解决签名不一致而卸载或清除数据。旧成绩保留，旧路线首次使用新流程时需要重新熟悉。

## 试用前了解

自动与全自动属于试验能力，不承诺全机型自动识别准确、锁屏后连续采样或特定减重效果；热量只是估算值。省电设置已允许也不等于连续采样已验证。

训练明细和旧单轮明细分别保留最近 100 条，更早记录保留汇总。普通备份包含路线、保留的成绩与归档统计，不包含全部原始运动文件、语音日志、偏好或进行中恢复点。原始运动数据需要另行导出。

本包不包含维护者的地图凭据，地图不可用时可手动填写路线；云同步、排行、社交与 iOS 不在当前试用范围内。
