# 循阶 · 每一步向上，每一层都算数

我把每天爬的楼，做成了一个 APP。

它叫「循阶」：一轮轮记录爬楼，停稳后确认实际楼层，训练中有语音反馈，结束后把成果“盖成楼”，还能回看记录、生成成绩海报。想让普通的一次爬楼，也留下看得见的进步。

**[查看宣传与下载页面](https://higlodev.github.io/steploop/) · [下载 Android 1.0.5 试用版](https://github.com/HigloDev/steploop/releases/download/v1.0.5-preview.1/steploop-1.0.5-android.apk) · [版本说明与校验表](https://github.com/HigloDev/steploop/releases/tag/v1.0.5-preview.1)**

这是面向愿意反馈问题的用户开放的 **Android 试用版（Pre-release）**。真实爬楼识别、锁屏连续采样、耗电及音频中断仍在验证，请先用手动模式完成短训练并确认楼层。

## 可以体验什么

- **训练记录**：无地图开练、路线选择和多轮训练，记录时间、步数及累计爬升。
- **自己确认楼层**：停稳后确认实际到达楼层，例如 1 楼到 15 楼，实际爬升为 14 层。
- **四种离线音色**：两种男声、两种女声，可选择与试听；无需在手机运行 AI 模型。
- **成果回顾**：盖楼动画、训练记录与趋势、可隐藏地点和身份信息的成绩海报。
- **本地数据**：无需注册账户，数据保存在手机上；支持成绩备份、CSV 和原始运动 JSONL 导出。

## 下载与第一次使用

1. 点击上方 **下载 Android 1.0.5 试用版**，取得 `.apk` 文件。GitHub 自动生成的 Source code ZIP 不是安装包。
2. 适用于 Android 7.0+ 的 ARM64 手机，推荐有气压计的设备；目前没有 iPhone 安装包。
3. 按系统提示允许当前浏览器或文件管理器安装应用，安装后打开循阶。
4. 选择“不用地图，直接开练”或已有路线，第一次建议手动模式、固定放在口袋或腰包、保持应用前台和屏幕点亮。
5. 停稳后结束本轮、确认楼层；保存后在记录页查看成绩。行走时不要操作屏幕。

**已安装早期个人内部版的用户**：本次公开试用包使用专用发布签名，可能无法覆盖旧内部版。请先备份，不要为解决签名不一致而卸载或清除数据。曾安装同一发布证书的 1.0.4 候选可覆盖升级，但仍建议先备份。

## 试用前了解

自动与全自动属于试验能力，不承诺全机型自动识别准确、锁屏后连续采样或特定减重效果；热量只是估算值。省电设置已允许也不等于连续采样已验证。

训练明细和旧单轮明细分别保留最近 100 条，更早记录保留汇总。普通备份包含路线、保留的成绩与归档统计，不包含全部原始运动文件、语音日志、偏好或进行中恢复点。原始运动数据需要另行导出。

本包不包含维护者的地图凭据，可以无地图开练；云同步、排行、社交与 iOS 不在当前试用范围内。
