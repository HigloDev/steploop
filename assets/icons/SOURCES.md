# 循阶图标原稿与生成说明

循阶的主要任务是开始训练、跟随指导、复盘数据和调整偏好。Dock 的视觉语义依次为上行台阶、佩戴哨子的运动教练、带数据柱的成绩单和圆角齿轮。一级入口和短操作采用清楚的外轮廓，确认、警告和防护等状态保留易识别的行业惯例。图形按实际显示尺寸检查线重、留白、重心和区分度。[设计师必看图标（icon）指南](https://www.woshipm.com/ucd/5299049.html)

所有母版由 Codex 内置 ChatGPT ImageGen 生成。下表记录每张图板的主题和提示词要点。

| 母版 | 图板内容及提示词要点 |
| --- | --- |
| [训练与导航](sources/training.png) | 4 × 4 独立图案。前三个主入口绘制上行台阶、有哨子和运动服的教练半身、带数据柱的成绩单，设置使用圆角齿轮。其余为楼层、电梯、轮次、目标、路线、心肺、课程资料、用户、群组、步行和跑步。 |
| [通用操作](sources/controls.png) | 4 × 4，使用圆端描边。箭头、增减、关闭、选择、编辑、删除、更多、撤销及重放。不同图形共用相近的光学尺寸。 |
| [状态与设备](sources/status.png) | 4 × 4，采用相同圆角线稿。提示、信息、帮助、暂停和播放、手机和显示器、权限、锁、通知、振动、声音和计时。 |
| [数据与工具](sources/data.png) | 4 × 4，按照无障碍、搜索、导入导出、分享、文件、表格、数据库、分析、运动指标和高度参照分格。 |
| [课程与进度](sources/badges.png) | 4 × 2，生成起点、终点、分层、闪电、阳光、羽毛、音乐和水滴。 |
| [细节修订](sources/reference-corrections.png) | 2 × 2，分别绘制月亮、包含篮板和篮筐的球框、正面带网的球门、轮廓内带闪电的电池。 |
| [应用标志](../brand/steploop/master.png) | 单个居中的三段上行台阶，由圆角连续带状结构形成。顶部浅冰蓝，向下回折的内侧为蓝色，在透明底上保留阶梯下方的开口。生成时要求省略文字、背景方块、外部阴影和多余纹理。 |

功能图板使用浅色背景上的深色图案。生成目标为一致的线条和圆端、宽松分格、无标注文字和装饰。打包脚本只裁切图格、提取透明度、缩放居中并导出方向变体。运行时通过语义颜色在浅色和深色主题中显示。品牌母版保留原始双色图形，单色场景使用同一轮廓。[可复现的资源打包脚本](../../scripts/package-imagegen-brand.cjs)
