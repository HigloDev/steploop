# 循阶 1.0.5 · Android 公开试用版

我把每天爬的楼，做成了一个 APP。每一步向上，每一层都算数。

[宣传与下载页面](https://higlodev.github.io/steploop/) · [下载 Android 安装包](https://github.com/HigloDev/steploop/releases/download/v1.0.5-preview.1/steploop-1.0.5-android.apk)

这是 Android 试用版（Pre-release），适合愿意体验并反馈问题的用户。没有 iPhone 安装包，也没有应用商店上架。第一次建议手动模式、固定携带位置、保持前台亮屏，停稳后确认楼层。

本轮目标是让用户在设置中选择沉稳男声 Uncle_Fu、年轻男声 Dylan、温柔女声 Serena 或明亮女声 Vivian，并直接试听。默认 Serena，选择保存在本机，重新打开应用后继续使用。

每种音色包含相同的 51 段固定提示和数字素材，共 204 段。使用本机 Qwen3-TTS 0.6B CustomVoice 的官方预置音色生成，无需在手机运行模型或联网合成。数字使用所选音色的素材拼接，避免中途切换系统声音。

这是新的 1.0.5 / Android code 6 候选，和既有 1.0.4 GitHub 草稿分开核验。旧内部签名手机不可直接覆盖安装公开签名包，不通过卸载来绕过签名差异。

## 本轮验证记录

2026-10-06 本地核对：487 项自动化测试全部通过（其中一项旧播报断言适配音色参数后单独复核），TypeScript、Expo Doctor 21/21、依赖窗口、恢复演练 6/6 与合成诊断链路通过。签名 APK 内置 JS，不依赖 Metro；204 段语音与素材清单哈希一致，未匹配到本机地图凭据。

隔离 Android 模拟器从同证书 1.0.4 覆盖升级后，原有路线和测试记录保留。四种音色均能选择并进入原生播放，试听完成后无失败提示；选择在冷重启后保留。模拟器与自动化检查不代表真实爬楼或声音主观品质验收。

真实爬楼、电梯、锁屏连续采样、音频中断、耗电和旧内部签名手机路线恢复仍在验证；自动与全自动为试验能力，不承诺所有机型自动准确或后台连续。热量为估算值。

## 安装和数据

- 包名 `com.zxn.palou`，版本 1.0.5 / code 6，Android 7.0+，ARM64 与 x86_64；推荐有气压计的 ARM64 手机。
- 使用独立发布证书。早期内部签名版可能无法直接覆盖，请先备份；不要为安装而卸载旧版或清除数据。
- 无需注册，训练数据保存在本机，可无地图开练。训练与旧单轮明细分别保留最近 100 条，更早保留汇总。
- 普通备份不包含全部原始采样、语音日志、偏好和进行中恢复点；原始运动文件需另行导出。
- 下载 `.apk` 文件安装。GitHub 自动 Source code ZIP 只含宣传页与项目介绍，不包含完整 APP 源码；本次公开范围是安装包、宣传页与发布说明。
