多轮记录使用 `calculateWorkoutSummary(...).totalFloors`，与这条记录正文完全一致，包含确认后的修正，排除待确认轮次。旧单轮记录使用原有起止楼层派生和缓存回退规则；待确认时取 0。首页楼栋模板和结算页保存楼栋的原稿图标保留，不把模板楼高当作训练完成量。
