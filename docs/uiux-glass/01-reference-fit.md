# 已确认原型与原生验收对照

本轮使用此前已确认的「冰川科技蓝 · 玻璃 Bento」六页原型。参考图为 `reference/approved-bento.png`。原型仅提供构图、材质、原创图形和交互表达。原生页面沿用实际功能及真实数据结构。

| 页面 | 从原型继承的视觉 | 原生验收重点 |
| --- | --- | --- |
| 首页 | 剪纸楼梯路线主卡、悬浮开始按钮、左大右小的周统计 Bento | 可编辑起点、可选楼栋、去所有记录、周分享、高度参照和未结束训练恢复 |
| 运动中 | 深海军蓝、独立的楼层大字、阶梯轨道、阶段说明、底部操作 | 上爬、下行、等待各有明确状态，单手操作，可取消长按，保存失败可重试 |
| 训练完成 | 同一阶梯标志的多面徽章，主数据及小卡，逐轮拆分 | 只有新完成触发庆祝，历史查看保持清楚。修正和分享仍可用 |
| 教练 | 剪纸楼梯的课程语汇，先显示本节行动，再看进展与课程日程 | 无课程可选择，有计划看当次、调整及复盘 |
| 记录 | 累计大数字与辅助信息，趋势图和历史明细分层 | 真实数据、搜索、趋势周期、个人最佳、记录详情和管理 |
| 设置 | 分组行、统一图标、自然选中与开关反馈 | 既有皮肤、音效、震动、偏好和备份路径完整 |

Dock 的四个剪纸折线主题与已确认原型一致。原图中的楼栋名、楼层、训练次数和示例数值只用于比较。真实页面不填入这些样例值。复杂背景降低透明度，操作标签和关键数据对比优先。
