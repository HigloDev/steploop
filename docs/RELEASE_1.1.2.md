# 循阶 1.1.2 · Android 公开试用版

本版完整落实黑橙界面和新品牌图标，完善首页、训练、结算、记录、设置及各原生弹层；首页新增 37 种高度参照，覆盖珠峰 8848.86 米，清单可查看进度及下一目标。训练记录的房屋、楼栋、高楼与双楼群按实际累计完成层数分为 7 档，修改成绩后同步更新。

## 下载与更新

下载 `steploop-1.1.2-android.apk`，支持 Android 7.0 及以上、ARM64 / x86_64，包名 `com.zxn.palou`，版本 1.1.2 / versionCode 11。

本版沿用 1.0.5 / 1.0.7 公开版签名，更新前先在旧版设置中保存备份，再覆盖安装。个人内部版使用不同证书，应使用对应内部升级包；签名不匹配时保留原应用和数据，不卸载、不清除数据，也不自动导入备份。

首次使用新楼栋时，首页点击「开始爬楼」，按提示完成第一轮逐层标定，保存后在「我的楼栋」选择它再次训练。此前旧路线首次进入新的流程时按界面完成标定。旧成绩继续保留。

## 验证范围

- 干净源码 `npm ci`、当前全量测试与 TypeScript 检查通过。29 个旧训练钩子测试及 4 个旧页面套件（43 项）因对应旧架构已删除而明确 skipped，详见 BUILDING.md；不将它们计作通过。
- 在独立 Android 15 模拟器从公开 1.0.7 / code 8 覆盖升级到本版，2 条合成训练及原有保存值保留，重启后保持；首页 37 种参照入口、原生清单打开关闭、旧记录显示通过。
- 公开 APK 的 1,421 个应用文件与已安装到维护者手机的版本逐项一致；差异为 Android 签名。该手机实际使用的是内部签名包。
- 小屏、大字体、浅色主题与 7 档图标的原生对照图册随源码提供。图册中的训练成绩是合成验收数据，不能证明真实运动准确率。

自动计层仍是试验能力，真实爬楼、电梯、锁屏连续采样、音频中断和耗电需要继续实测。热量是估算值。山峰海拔仅作高度对照，不代表实际登顶。公开包不包含维护者地图凭据，地图不可用时可手动填写信息。

普通备份不包含全部原始运动文件、语音日志、偏好和进行中恢复点；这些证据需要另行导出。当前不包含云同步、排行、社交或 iOS 发布。
