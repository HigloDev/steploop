反馈使用问题
旧版本可以直接更新吗？+

从本网站下载的旧公开版可使用相同发布签名覆盖更新。更新前，请在“设置 → 备份与导出 → 保存备份到下载”保存一份备份。1.1.5 补全了楼栋模板备份，升级后建议重新导出。内部测试签名可能不同；遇到签名冲突时请保留原应用与数据，通过问题反馈联系维护者。

自动计层的结果准确吗？+

自动计层仍处于试用阶段，结果受手机传感器、携带位置和环境影响。请在训练结束后核对、修正楼层。真实运动、锁屏连续记录和耗电仍需更多验证；页面演示不代表准确率承诺，热量为估算。

需要注册或者联网吗？+

无需注册。训练与记录保存在本机，可在设置中导出备份。下载安装和打开外部链接需要网络；公开包未配置在线地图，按楼栋设置即可开始训练。

支持哪些手机？有 iPhone 版吗？+

本次提供 Android 7.0 及以上的 ARM64 与 x86_64 安装包。自动计层体验取决于机型传感器能力，请根据应用提示使用。目前没有可公开下载的 iPhone 版。
