# 设置页间距修正 · 1.1.5

已在 Xiaomi 14 上从 1.1.4 / 13 原位升级到 1.1.5 / 14，完成设置页显示与导出数据核对。

## 改动

- `NativeChoice` 通过容器 `onLayout` 与原生文字 `onTextLayout` 决定排布，不再在字体倍率达到 1.25 时一律拆行。空间不足时采用平衡的多行排布，单项至少保留 48 dp 点击高度；长文字可随内容增加高度。测量节点不参与无障碍读取。
- 播报模式标题与音量、语速采用同一文字层级；标题到控件间距为 8 dp，设置块之间为 16 dp。
- 设置卡片统一为 16 dp 间距。双行条目补足 12 dp 上下内边距；权限名称、状态与分隔线之间留出空间。
- 偏好读写、训练数据、导出与权限操作沿用现有接口。

原生截图中短选项均完整显示，权限标题、状态及分隔线没有挤压。最终手机停留在设置页顶部。系统字体倍率未改变。
