# 分段 MET 热量试用说明

开发候选为 1.1.6 / Android code 15，基于公开 1.1.5 的主版本。公开 Release、标签和附件不变；本包不含并行开发的教练功能或独立保留的审计修复分支。

## 使用

在设置页体重下选择慢速、一般或快速；未选择时默认一般，并保存默认来源。训练页展开“热量估算依据”可以切换速度，调整只影响之后记录的净运动片段。结果页可查看体重、片段用时、档位和计算依据。

慢速 4.5 MET、一般 6.8 MET、快速逐级上楼 9.3 MET，来自 [2024 身体活动汇编](https://pacompendium.com/walking/)。新训练的活动热量使用 `Σ max(MET - 1, 0) × 体重kg × 片段小时数`，只计引擎记录的上行活动时间，不补算休息、下行、采集缺段或额外恢复耗能。活动类型不明确时会标注按上爬阶段估算。没有新增心率接入，也没有修改计步、楼层或气压判定阈值。

实时、语音和分享取同一结果，只在所有片段相加后统一取整。新训练保存体重和算法快照，各轮保存分段依据，完成后固化估算结果；修改体重偏好、生成分享或核对层数不会重算已有热量。

## 原有数据与升级

1.1.5 旧记录继续使用原来的爬升高度、活动时间和轮间休息估算。不存在旧记录批量改算或删除操作。带新版依据的备份导入后保持原结果；缺少分段依据时明确标示，不凭最后档位补算。

安装前在原应用导出备份。APK 沿用包名 `com.zxn.palou` 和公开版发布签名，直接覆盖安装。不要卸载或清除数据；若系统提示签名不一致，保留原应用并停止安装。早期内部签名版本需要另行核对，不能靠卸载解决。

设备上的已有训练数据不参与构建测试。升级保留验证在隔离模拟器使用合成训练记录进行；它不能代替用户手机和真实运动验收。
