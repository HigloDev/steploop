## 现场验收步骤

1. 对固定 APK 核对版本和 SHA-256。新用户安装用隔离设备，现有手机先核对签名与备份。
2. 无地图、手动模式完成第一轮，确认实际楼层；返回起点后完成第二轮。
3. 结束后核对各轮与累计；关闭再打开应用，确认记录仍在。
4. 导出普通备份和本次训练 JSONL，核对能解析、楼层与时间一致、缺段如实记录。
5. 另行尝试锁屏，记录实际传感器时间轴和电池状态。失败不写作通过。

机器构建、模拟器交互、真实手机运动三种证据分别记录。本轮不卸载手机应用、不清除真实数据、不自动导入旧备份。
