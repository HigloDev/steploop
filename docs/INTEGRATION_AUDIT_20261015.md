| 领域 | 可复现问题 | 修复与证据 |

| 首次引导 | 快速点击越界；重复完成或离开后异步导航 | 有界递进、完成单飞、卸载保护 |

| 楼栋备份 | fusion模板不进入普通备份，换机丢模板 | 可选兼容字段纳入导出、预览、合并/替换、回滚与撤销 |
| 备份统计 | 替换仍沿用本机账本；撤销丢归档统计 | 显式采用备份账本，撤销逐键恢复账本和裁剪统计 |
| 并发保存 | 楼栋读改写竞争覆盖；缓存覆盖导入结果 | 共享串行队列、移除陈旧缓存 |
| 多次标定 | 第二次标定覆盖第一次未保存的模板草稿 | 按workoutId独立保存和清理，兼容旧单对象 |
| 存储故障 | 日志读取/解析/恢复失败被当成没有日志 | 显式拒绝后续数据写入，保留日志，故障解除可重试 |
| 事务提交 | 提交标记失败未纳入回滚 | 提交标记也在事务保护范围；验证读回一致性 |
| 检查点 | 完成后旧异步写可能复活检查点 | 写入/清除按共享队列排序；恢复读取等待退出清理 |
| 训练生命周期 | 卸载与原生启动竞争，残留采样或旧清理关闭新训练 | 跨挂载清理屏障、单次停止、取消后的事件隔离 |
| 采集时间 | JS延迟回调被当成真实运动时刻/采样中断 | Expo原生秒时间戳映射同一时钟；保留现有pressureT原生契约 |
| 多轮训练 | 无气压时旧步数触发下一轮 | 起步窗口不跨越进入等待状态的时间 |
| 结束保存 | 原生日志未回放就结束引擎，丢最后已采集样本 | 固定结束时刻、停止采集、排空日志后再冻结与保存；失败可重试 |
| 原生日志 | 高序号实时事件越过尚未回放的缺段 | 日志为准，回放失败不推进缺段后的游标 |
| 界面异常 | 渲染异常没有用户恢复入口；失败检查点被当成清理成功 | 根ErrorBoundary提供重新打开；保留未写盘快照并重试，持续失败时阻止新训练；成功保存/主动放弃后清除内存快照，避免复活 |
| 依赖 | 缺少音频peer、自动主题模块及SDK补丁不匹配 | Expo SDK57补丁对齐，直接安装expo-asset/expo-system-ui |
| 持续验证 | 缺少默认分支/PR自动验证 | 固定SHA的CI：干净安装、类型、全量回归、SDK匹配、Android JS导出 |
