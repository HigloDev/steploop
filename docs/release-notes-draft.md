## 1. 本版本新增（代码 + 自动化证据已确认）

- **不用地图也能开练**：没有定位、没有既有模板也能直接开始；第一轮边爬边建立模板。
  地点从「必须」变为「可选」，缺地点只影响地图相关统计，不阻塞训练。
- **训练计划**：可选热身、每轮返回与轮间恢复；可跳过可选阶段；热身与休息时间**不计入**上爬成绩。
- **人工修正成绩**：结果页可修正本轮最终楼层；修正会保留原值、记录原因，且修正过的轮次不参与算法学习。
- **更长的历史**：明细仍保留最近 100 条，但更早记录的长期统计（次数、楼层、爬升、净时长、按天分布）
  会被归档保留，归档条数在历史页可见；备份会一并携带归档统计。
- **进步视图**：周 / 月 / 季趋势、同路线最佳单轮、周目标完成度。
- **后台缺段告知**：切到后台或锁屏期间系统会暂停传感器，回到应用后会明确提示「这段时间没有记录」，
  而不是让用户爬完才发现少了楼层。
- **无障碍与分享**：按钮/开关具备读屏角色与状态；减少动画时改为静态展示；
  分享文本与海报**不含地点**；分享面板被取消时不显示「分享成功」。

## 2. 行为变化（请用户在升级前知悉）

1. 训练入口从「路线页」移到「训练」页；路线页只负责路线管理。
2. 缺地点的路线现在**可以直接开始训练**（旧版本会要求先补充地点）。
3. 历史记录超出 100 条时不再显示「将自动丢弃」——改为归档为统计。
4. 分享按钮的反馈更保守：只有「保存到相册」成功才算成功；系统分享面板返回不再提示成功。
5. 计划训练默认**关闭**，需要时在训练设置里打开。

## 3. 已知限制（必须与发布说明一起出现）

| 限制 | 影响 | 说明 |
|---|---|---|
| 锁屏/后台不采样 | 锁屏期间的楼层不会记录 | 平台限制；应用会提示缺段，可在本轮结束后修正最终楼层 |
| 手持使用 | 识别鲁棒性较弱 | 正式训练请用口袋或腰包；手持仅用于试跑与校准 |
| 无气压计机型 | 楼层边界判定保守 | 会降低置信度，但不会伪造楼层；界面如实提示 |
| 分享结果不可确认 | 不显示「分享成功」 | Android 平台不在分享面板返回时回报结果；只有保存图片有明确信号 |
| 历史明细上限 100 条 | 更早的记录看不到逐轮明细 | 长期统计仍完整保留 |

## 4. 升级与数据安全

- 升级目标是保留路线、训练记录与恢复点；实际是否保留必须核对升级前后数据，不能仅凭代码承诺。
- 已归档记录的统计会随备份一起迁移；**旧备份文件**（不含归档统计）导入后仍可用，只是不含已归档部分。
- **数据库升级后不要直接装回旧版 APK**（可能不可读）。回退步骤见 `docs/ops-and-rollback.md`。
