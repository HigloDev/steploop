# 可信训练版基线

## 冻结范围

- 基线名称：`trusted-v1`
- Expo SDK：57
- 算法入口：`RouteRecognizer`、`FreeRecognizer`、`StairTurnGate`
- 诊断格式：V1（后续实现继续兼容读取）
- 核心测试：以 `npm test` 的成功输出为准

## 发布门槛

| 类别 | 指标 | 门槛 |
|---|---|---:|
| 算法 | 最终楼层准确率 | ≥ 98% |
| 算法 | 楼层事件 Precision / Recall | ≥ 96% |
| 算法 | 负样本误报率 | ≤ 1% |
| 算法 | 识别延迟中位数 / P95 | ≤ 2 秒 / 4 秒 |
| 稳定性 | 完整训练无崩溃率 | ≥ 99.8% |
| 产品 | 老用户冷启动至开练中位数 | ≤ 10 秒 |
| 产品 | 完整训练完成率 | ≥ 90% |

## 发布阻断项

- 真实验证集未达到门槛时只能发布封闭测试版。
- 高德 Key 必须在控制台完成轮换与应用来源限制。
- Release APK 必须在断开 Metro 后独立启动。
- 路线、训练、设置和备份迁移不得丢失旧数据。

## 已知边界

- 当前正式支持裤袋与腰包；手持只作为鲁棒性样本。
- 无气压计设备必须降级并降低置信度上限。
- 合成测试只能保护逻辑回归，不能证明真实准确率。
