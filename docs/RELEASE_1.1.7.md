## 安装与升级

下载 steploop-1.1.7-android.apk。支持 Android 7.0 及以上，包含 arm64-v8a 与 x86_64。

公开包沿用 1.1.5 公开签名。升级前在设置中导出备份，再覆盖安装，升级后检查楼栋、历史训练与课程。内部版使用不同签名，内部用户应继续使用相同内部签名更新包，遇到签名冲突请保留原应用和数据。
