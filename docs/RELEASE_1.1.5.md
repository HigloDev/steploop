# 循阶 Android 1.1.5 公开试用版

发布日期：2026-10-21。Android versionCode：14。包名：`com.zxn.palou`。标签：`v1.1.5-preview.1`。

## 本次更新

- 训练首页、运动中、结算、记录、设置和周分享统一为冷白、深蓝与钴蓝视觉。
- 首页集中展示本周爬升、七天训练和常用楼栋；运动中突出当前楼层与进度，结算支持逐轮核对。
- 记录页支持按楼栋和日期查找；设置选项根据实际文字和容器宽度排布，改善大字体下的行间距。
- 包含此前分支整合中的训练结束、备份完整性、恢复与误操作修复；Expo SDK 57 补丁依赖已对齐。
- 公开下载页按新版界面重做，直接提供本版本 APK、更新说明与校验文件。

## 下载与更新

支持 Android 7.0 及以上，安装包包含 ARM64 与 x86_64。APK 内置 JavaScript，可独立启动，无需连接开发服务器。

使用既有公开发布证书，旧公开版可覆盖升级。更新前，请先在“设置 → 备份与导出 → 保存备份到下载”保存备份；升级后重新导出一份包含楼栋模板的新备份。内部签名安装包可能无法被公开包覆盖；遇到签名冲突时保留原应用与数据，通过仓库 Issue 反馈。

公开包未嵌入维护者的在线地图凭据，按楼栋设置即可训练。无需注册，训练记录保存在本机。

## 试用边界

自动计层仍在试用阶段，受手机传感器、携带方式和环境影响；请在训练后核对、修正楼层。真实爬楼准确性、锁屏和后台连续采样、较长训练的耗电及其他机型仍待现场验收。热量为估算。
