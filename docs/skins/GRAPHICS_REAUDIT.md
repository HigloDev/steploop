## 已定位的原因

| 位置 | 先前问题 | 整改方向 |

| K-On训练/教练 | 木台贯穿整个图片下沿，最下行几乎全部不透明 | ImageGen保留物件，木台改为局部、有机透明收边；原生浅暗复核 |

| 初号机训练、山野设置 | 机体或石块在底部形成局部切口 | 对应素材修复后检查实际背景 |

| K-On教练 | 宽图居中导致右侧镲片被裁 | 按右侧主体锚点摆放，核对乐器完整 |

## 本次恢复后的整改

山野心肺课程图已完成生成，楼栋图复用中断前已返回的合格结果；两者经肉眼检查后原字节接入。总素材为60张，其中30张四入口浅暗页头、18张共享角色、12张细节素材。素材来源和哈希见`assets.json`及`asset-provenance/edge-r2.json`。

定点试拍另外发现K-On教练页的琴头压到说明文字，已将完整乐器组缩小并下移到单独的图像区域，保持下沿完整。两套EVA记录页的NERV标识已与搜索按钮分开。最终验收使用`round-7`，按源码指纹恢复已完成截图；自动任务记录每组命令的退出状态，避免静默等待。

并排对照还发现短页头的透明留白被一并缩小，导致K-On/EVA/皮卡丘设置图案过小。已为这些稀疏画布登记显示窗口，读取像素验证窗口外Alpha最大为1（皮卡丘为0），图案主体未裁切。皮卡丘设置图案的原稿遮挡直边与下方卡片对齐，并仅在记录/设置原图下沿10像素内柔化Alpha；原RGB全部保留，变更来源及SHA记入清单。

本次验收脚本另修复两项环境误判：在同一个有限超时内重试新页面暂不可用的无障碍树；拒收React Native的蓝色Refreshing横条。一次模拟器System UI无响应已恢复，旧运行记录保留在本地输出目录。应用错误和最终截图异常仍使验收失败，不能以重试替代检查。
