# 皮肤建设索引

本文件是循阶所有皮肤工作的统一入口。先登记、再实现、再验证；不能只改首页颜色或只交一张概念图就标记完成。机器索引见 [registry.json](registry.json)，建设规范见 [CONSTRUCTION.md](CONSTRUCTION.md)。

## 产品约定

- 用户分别选择“皮肤”与“明暗模式”。明暗模式提供 **跟随系统 / 浅色 / 暗色**，切换皮肤不重置明暗选择。
- 当前目录共 **7 套皮肤、14 套明暗配色**。跟随系统是解析规则，不是第三套配色。
- 默认 **原版钴蓝＋跟随系统**。原版保留1.1.5既有颜色和页面结构；先前“清爽原生”概念稿将周卡改浅，并不是原版逐像素复制，不能替换原版基准。
- 选择后立即在应用内生效并持久保存。下次启动恢复选择，保存失败有明确提示与重试入口。
- 皮肤只改变显示层，不改变训练算法、成绩、楼栋、备份、手势语义或训练状态。正在训练时切换明暗不重建训练流程。
- 配色皮肤沿用循阶自身图标与组件。EVA、皮卡丘、K-On在这里指配色灵感；本轮不添加人物、机体图片或额外功能。

实际页面从 [原生对照图册](preview.html) 查看，检查范围见 [验证记录](VALIDATION.md)。原版首页、训练和完成页保留1.1.5基准；分享海报改为随所选明暗显示，旧版固定浅色的海报不再限制其他皮肤。

## 初始目录

| 稳定ID | 显示名称 | 浅色方向 | 暗色方向 |
|---|---|---|---|
| `classic` | 原版钴蓝 | 冷白、钴蓝、深蓝周卡 | 深蓝、浅蓝强调；沿用1.1.5 |
| `night-run` | 夜跑竞技 | 冷白底、深炭周卡、荧光黄绿操作 | 炭黑底、荧光黄绿强调 |
| `woodland` | 山野自然 | 米白、松绿、鼠尾草辅助色 | 深森林绿、浅鼠尾草强调 |
| `eva-unit-01` | EVA 初号机 | 淡紫白、机体紫、荧光绿点缀 | 深紫黑、亮紫与荧光绿 |
| `eva-unit-02` | EVA 二号机 | 暖白、机体红、橙黄点缀 | 深炭红、珊瑚红与橙黄 |
| `pikachu` | 皮卡丘 | 奶黄、明黄操作、深棕文字 | 深棕黑、明黄与暖米白 |
| `k-on` | K-On | 奶油白、莓粉与茶褐 | 可可棕、柔粉、奶油白 |

K-On先采用“放课后茶会”的整体配色，不按单个角色拆分。以上是本项目的可用性配色方案，不是声称存在官方UI色值标准；灵感来源见 [SOURCES.md](SOURCES.md)。

## 单一来源

- `registry.json`：建设目录、稳定ID、状态与证据入口。
- `src/skin-catalog.ts`：运行时目录及成对配色数据；选择页从此自动列出皮肤。
- `src/theme.ts`：现有主题的唯一显示层入口，输出完整语义token、训练配色与海报配色。不能另建一套平行主题系统。
- `src/services/appearance.ts`：外观偏好唯一存储所有者，独立键 `steploop.appearance.v1`；不重写既有训练偏好对象。
- `src/appearance.ts`：React订阅入口；页面通过 `useTheme()` 取当前主题。

## 建设阶段

| 阶段 | 交付及通过条件 |
|---|---|
| 目录与规范 | 7套已登记；原版与概念稿的区别明确；浅暗完整覆盖范围明确 |
| 主题引擎 | 14套完整token；稳定ID、异常回退、文字/背景对比度检查通过 |
| 用户入口 | 设置中可选皮肤和明暗；选择立即生效；保存失败可见并可重试 |
| 全应用接入 | 导航、训练、完成页、原生控件、弹窗及海报都随外观变化 |
| 自动验证 | 旧偏好兼容、读取失败、连续选择、写失败重试和原版基准通过 |
| 原生验证 | 7×2×3核心页截图共42帧；另外验证选择、重启、系统切换和大字体 |
| 发布 | 单独标记候选、实际包和验证范围；不因为源码完成就改写现有1.1.5 Release |

各皮肤实际完成状态以机器索引和验证记录为准。未完成原生截图或真实交互验证时，不能标记为全部验收通过。

## 后续新增皮肤

1. 在机器索引登记新ID、名称、配色方向和验证范围，禁止复用旧ID表示另一种皮肤。
2. 在运行时目录提供浅色、暗色两套配色。页级代码不能按皮肤名称写颜色分支。
3. 运行目录一致性、完整token、对比度、偏好与回归检查。
4. 同状态、同数据、同字号捕获首页/训练中/训练完成六帧，补齐设置、弹窗、空态、失败态与分享检查。
5. 记录证据路径和实际结果后再更新状态。使用 [新皮肤记录模板](TEMPLATE.md)，验收约定见建设规范。
