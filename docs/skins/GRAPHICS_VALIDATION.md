# 1.1.7 图形皮肤验证

状态：本轮原生功能、主要版式与响应式适配验收通过；七套索引标记为`native-verified`，未标记公开发布。

以综合候选`9c7eed9`为基线，分支`codex/skins-graphics-117-20261028`。公开版本仍为1.1.5 / code14，本候选为1.1.7 / code16。原版、夜跑、山野、EVA初号机、EVA二号机、皮卡丘、K-On共7套，均支持浅色、暗色和跟随系统。

## 使用方式

“设置 → 皮肤与外观”点选皮肤和明暗模式，立即生效并分别保存，冷启动恢复。“反馈预览”可展开试用楼层震动和盖楼结算，预览不产生训练记录。

## 实现与素材

保留四入口、教练数据、训练流程与语义主题。六套图形包含18张共享Logo/场景/完成图、24张四页页头、5张暗色覆盖，全部本地打包。`assets.json`记录精确尺寸、字节数、SHA-256、来源与裁区；装饰不接收触摸、不进入无障碍焦点，失败时隐藏或Logo回退。

皮卡丘经用户明确批准从确认稿提取，另五套按要求使用ImageGen参考编辑。被UI遮挡的画面不补画，放大不增加细节。[逐页对照](fidelity-review.html)只在浏览器中按CSS显示原始裁区，不修饰图片。[原生图册](graphics-preview.html)展示实际页面。

## 验收结果

类型检查通过。`npm test`共767项，734通过、0失败、33项原有跳过；包含35项主题/偏好/素材检查及Android 130%浮点边界回归。普通入口`index.ts`的Android导出通过，Hermes包为`index-464191efcbb9c4fb621f2b8d1ef1ca18.hbc`（4,849,055字节）。命令、退出码、日志哈希与源码指纹见`evidence/20261028-fidelity/automated-results.json`。

原生调试壳已构建且只安装专用模拟器；本轮页面从对应源码的Metro运行。它不是已发布APK。最终160张截图及全部实际交互已通过，原始PNG未修饰。

## 剩余差异

生成插画与Logo仍有原画细节差异；皮卡丘源像素有限，近看边缘较软。动态图表与记录保持真实算法，不复制概念稿的假数值。完整整改见项目根目录`design-qa.md`。

本轮不宣称逐像素100%一致，也不推导真实运动、锁屏或能耗结论。实体手机和公开Release分别登记，[旧1.1.5配色验证](VALIDATION.md)保留为历史证据。

## 最终结果

84张核心页（含48组原稿同宽高比对照）、30张教练/阶段/失败/海报页、32张小屏与130%字号、14张实际交互，共160张。全部对应源码/素材指纹`23d61f36a33900d6ed56baa5031f6f40920938e7c8c87ac5d6651f68d7e40cf8`。严格检查通过，图册不混入旧源码截图。

实际验证：四个底栏往返、七款选项、外观与明暗分别保存、冷启动恢复、跟随系统即时变化及手动优先；目标/称重/复盘保存及重启后读取；未完成课程保留确认楼层；反馈预览展开、退出且记录数仍为4；短按不结束、长按1.6秒进入已保存结果。小屏主要操作均滚动到完整可点击区域，至少48dp并启用。
