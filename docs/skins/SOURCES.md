# 配色参考与取值边界

所有HEX值都是为循阶UI可读性选择的项目值，不声明是作品的官方色彩标准。

- 原版：仓库1.1.5的 `src/theme.ts` 与 `docs/assets/site115/` 六张原生页面截图。
- 夜跑竞技、山野自然：本会话已展示的概念方向，分别保留黄绿运动感及米白松绿方向。实现与原生证据分别见目录和验证记录。
- EVA初号机、二号机：官方商品图中的机体紫/绿和红/橙方向。[Takara Tomy EVA商品页](https://www.takaratomy.co.jp/products/metacolle/evangelion/index.html)
- 皮卡丘：明黄、深棕黑与少量红的角色配色方向。[宝可梦官方图鉴](https://zukan.pokemon.co.jp/detail/0025)
- K-On：以轻音部与放课后茶会氛围为整体方向，采用奶油、莓粉和茶褐，不按单个角色划分。[TBS官方页面](https://www.tbs.co.jp/anime/k-on/k-on_tv/)

文字和状态可读性检查参考 [WCAG文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。本轮测试验证成对token的对比度，不据此宣称应用通过完整WCAG认证。

作品名仅用于辨认用户要求的配色灵感。运行时使用循阶现有图标与组件，不将参考站的图片放入应用资源。
