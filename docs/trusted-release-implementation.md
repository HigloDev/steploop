# 可信训练版实施状态

更新日期：2026-09-10

## 已落地工程能力

- 识别器统一输出运动、气压、转弯和路线模板证据；低置信度只进入候选楼层。
- 已验证路线满足多证据与 0.90 置信度后进入 3 秒自动完成窗口，并支持撤销（开始训练倒计时已移除，两者不是同一机制）。
- 诊断包升级为 V2，兼容读取 V1；记录采样质量、气压质量、算法/参数/路线模型版本和匿名设备组。
- 离线回放支持目录、文件清单 SHA-256、分组报告和发布门槛校验；`invalid` 样本不进入指标汇总。
- 路线模型升级为 V3，采用可信轮次、分布统计、有界更新、冲突复核和惰性迁移。
- 备份导出升级为 V2，并继续接受 V1；旧路线只在 V3 成功写入后切换存储键。
- 训练记录增加可信质量、纠正次数、完成来源、个人最佳资格和周目标贡献。
- 首页增加本周数据和最近路线一键开始，距离排序不主动索取定位权限。
- 训练页强化楼层主视觉、状态语义、震动语义、低置信度人工确认和自动终点撤销。
- 结果页增加同路线个人最佳与可追溯的规则建议。
- Android 权限收敛到定位、活动识别、震动和联网；读相册、旧外部存储、身体传感器和高频传感器权限已从最终 Manifest 移除。
- 高德配置改为本地/构建环境注入，不再直接保存在业务源码。

## 仍然阻断公开发布的外部验收

- 第一轮与第二轮真实传感器数据尚需测试员按矩阵采集；没有冻结验证集就不能声明达到准确率门槛。
- 8 款 Android、30 分钟耗电/温度、来电/锁屏/杀进程和 TalkBack 仍需人工真机矩阵执行。
- 高德旧密钥必须在高德控制台轮换，并限制 Android 包名、签名和 Web 来源；环境变量只能防止密钥直接进入源码，不能把客户端密钥变成秘密。
- Release 签名包、升级不丢数据和断开 Metro 独立启动需在正式签名配置可用后验收。
- Expo Doctor 的远程 schema 检查需要能访问 Expo API；本次本地执行因 TLS 网络连接失败未获得完整结果。

在以上真实数据和发布矩阵全部达标前，构建只能标记为封闭测试版。
