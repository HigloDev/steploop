# 1.1.9 Impeccable 全面审计与整改

以 `com.zxn.palou.uiqa` 的首个 1.1.9 Android 21 隔离包为审核起点。设备 24031PN0DC，Android API 36，1440×3200，560dpi，约 411dp，字体 125%。按 Impeccable Android 审计、动效和质量规范核对。浅深两套各打开 18 个真实页面，使用同一组合成记录。

| 维度 | 初审 | 证据与影响 |
| --- | ---: | --- |
| 无障碍 | 2/4 | 主要操作已暴露标签，Dock 首次实点未完成切页。完整 TalkBack 焦点顺序待验。 |
| 性能 | 2/4 | 旧模拟器帧时样本偏高。新盖楼用了本地原生解码，真机切页和实际播放需要复评。 |
| 外观与主题 | 2/4 | 运动浅色已跟随设置。部分悬浮层覆盖底色太实，滚动时玻璃后方层次弱。 |
| Android 平台 | 2/4 | 安全区与真实长按入口可见。真机 Dock 和部分标签跳转出现失败。 |
| 适配 | 3/4 | 411dp／125% 的 36 组页面成功取证。新整改包的小屏和更大字体需要单列测试。 |

初审 11/20。平台结论为关键导航需要整改。启动训练的真实触控成功，故障不能归为手机全局禁止输入。

源码类型检查通过。最终源码回归共 772 项，739 通过、0 失败、33 跳过。隔离验证使用合成训练记录。TalkBack、低版本设备的动态虚化退化和真实楼梯识别保留独立验收。设备厂商限制了新建输入测量工具的独立 APK 安装，复测使用现有隔离包与 Android 自带触屏输入。

## 签名包及数据连续性

`output/uiux-119/steploop-1.1.9-android21-arm64.apk` 是 `com.zxn.palou` 的 1.1.9 / versionCode 21 签名 ARM64 包，安装文件 152,370,649 字节。SHA-256 为 `F10D8E3A4FB2165890BF93BBF7EA731787A6708E70BC80F98A5A2E670917AFEE`。加上离线盖楼素材后，比手机原包增大约 17 MB。包名、签名证书和 13 项声明权限核对一致。
