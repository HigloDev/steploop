# 真机回归清单

在发布新版本或改动核心逻辑后，按此清单在真机（Android）上回归。
前置：`npm run check`（tsc + expo-doctor）与 `npm test` 均通过。

## 环境准备

- 真机开启开发者选项，`expo run:android` 或安装 release APK
- 准备一栋有楼梯的楼（至少 2 层以上）
- 手机需支持气压计（优先），无气压计设备也要验证降级路径

## 核心链路

### 1. 新路线首次开张（边爬边建模板）

- [ ] 首页新建路线 → 地图选点 → 路线档案显示「首次采集」引导
- [ ] 开始首次采集：确认「首次开张模式」提示出现
- [ ] 爬 2~3 层，楼层随气压上升而推进（无气压计则按步数估算）
- [ ] 点击「到达终点」，输入真实终点楼层，生成模板提示出现
- [ ] 进入返回阶段：气压辅助显示相对起点高度，接近起点自动弹「确认返回起点」
- [ ] 回到起点后进入休息页，历史中该路线学习进度 = 1

### 2. 正式多轮训练

- [ ] 路线档案 → 训练设置（目标轮数/楼层/爬升/时间均可设）
- [ ] 第 2 轮起使用模板识别：每层到达有震动反馈，楼层卡片推进
- [ ] 完成一轮 → 本轮成绩 + 与上一轮对比
- [ ] 连续多轮（≥3）：轮次轨道、最快/平均轮正确
- [ ] 目标达成提示出现，可继续加练或结束
- [ ] 训练总结页：汇总数据、每轮列表、路线学习状态正确

### 2.5 卡路里与净爬楼时间（静止不计时）

- [ ] 进入训练后静止不动（不爬楼）：顶部「消耗 千卡」保持 0 不增长，「净爬楼」指标不增长，本轮挂钟只体现在「训练 总历时」
- [ ] 停止运动再继续爬：净爬楼只累计动作时间，最终轮次/总结/历史/海报的净爬楼与卡路里一致
- [ ] 无气压计设备同样生效（步数/能量判定与气压无关）

### 3. 返回阶段

- [ ] 乘电梯下楼：不误报楼层推进，能正确触发「确认返回起点」
- [ ] 走楼梯下楼：波形可视化显示下楼/转弯
- [ ] assisted 模式自动触发 + manual「还没有」回到返回

### 4. 检查点恢复

- [ ] 训练中锁屏/切后台，杀进程后重启：弹出「发现未结束的爬楼训练」
- [ ] 「继续训练」：从下一轮 round_ready 开始，中断轮在历史中标记「含中断」
- [ ] 「结束并保存」：中断轮进入历史记录
- [ ] 「放弃保存」：检查点清除

### 5. 分享海报

- [ ] 训练总结 → 制作分享成果：3 模板 × 3 比例切换正常
- [ ] 保存到相册、系统分享、复制数据均可用
- [ ] 地点可切换名称/隐藏

### 6. 历史与设置

- [ ] 历史页：Workout 卡片与旧版单轮记录并存，筛选正常
- [ ] 顶部「完成次数 / 累计爬升」与数据一致（不再依赖文本解析）
- [ ] 设置：体重修改影响卡路里；导出备份 → 导入备份数据完整

## 边界与回归

- [ ] 无气压计设备：首次开张按步数估楼层、返回阶段仅手动确认
- [ ] 传感器中断（切出 App 再回来）：中断时间不进入净爬楼用时
- [ ] 路线删除后：历史记录仍可查看（快照渲染）
- [ ] 深色/浅色主题切换无布局错乱
- [ ] Android 返回键：训练中触发结束确认，不直接退出
