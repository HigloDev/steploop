# 循阶 1.1.2 使用与备份

## 开始训练

1. 首页点击「开始爬楼」，确认起始楼层。
2. 新楼栋的第一轮按提示标定，到平台停稳后确认实际楼层，保持同一种携带方式。
3. 结束后检查成绩并保存楼栋；下次在「我的楼栋」选择它开始训练。
4. 训练中通过页面内的操作暂停、继续或结束；发现计层偏差时按实际楼层修正。
5. 结算页确认保存，记录页可筛选历史、检查成绩和分享。

首页「查看 37 种高度参照」展示每项进度。建筑使用自身高度，山峰使用海拔，仅作高度对照。记录中的房屋和楼群是按完成层数分档的示意，精确成绩以正文为准。

## 升级与备份

更新前在设置中展开「备份与导出」，选择「保存备份到下载」。文件保存在 Download/循阶。公开 1.0.5 / 1.0.7 用户下载 `steploop-1.1.2-android.apk` 覆盖安装；内部签名版本须使用匹配证书的内部包。遇到签名不匹配时保留原应用和数据，不卸载、不清除数据，也不自动导入备份。

旧路线首次进入新的楼栋流程时按实际界面完成标定。旧成绩仍由记录页保留。原始运动文件、语音日志、偏好和进行中恢复点不全部包含在普通备份里，需要时另行导出原始证据。

## 手机设置与试用边界

设置页可查看运动、通知及电池优化状态，按系统提示处理。允许后台运行仍不代表锁屏连续采样已通过实测。首次试用建议短距离、前台亮屏，按实际楼层核对成绩；发现偏差请记录版本、手机型号、Android 版本和复现步骤。不要把自动识别结果当作安全判断。

通过 [Issues](https://github.com/HigloDev/steploop/issues) 反馈；不要公开上传包含路线位置和个人记录的完整备份。
