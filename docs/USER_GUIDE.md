# 安装、备份与更新

## 安装和第一次训练

从项目 Releases 下载 1.0.7 APK，在 Android 文件管理器中打开安装。进入“我的路线”，添加路线或导入别人分享的路线文件。可以使用定位和名称建议，地图不可用时手动填写即可。

新建路线先“熟悉路线”：逐层走两遍，到每层平台停稳后确认楼层；再完成逐层检查和正常爬楼检查。有电梯时还需检查电梯上下，最后检查平地行走和休息。按页面提示完成，不必一次做完。检查没有通过就不会显示准备好了。

导入的路线保留参考信息，还需要在自己的手机上完成检查。文件导入会先显示内容，同名另存；它不包含分享者的个人训练成绩。原有路线也要完成新流程才能开始新的正式训练，旧成绩继续保留。重新熟悉会另建一份路线，目前不能单独重录某一层。

准备完成后，从首页开始爬楼，结束后查看成绩。熟悉路线时固定携带位置，保持应用前台和屏幕点亮，到平台停稳后再点按钮。

手动模式由你结束本轮和开始下一轮；自动模式在关键转换时需要确认；全自动在证据满足条件时自动转换，但目前仍是试验功能。运行中始终可以人工接管。

首次建议保持屏幕点亮和应用前台。若要尝试锁屏，在训练页或设置页查看省电状态，并通过应用入口打开本应用的系统电池设置。返回后会重新读取状态。系统授权并不能保证所有机型都不断采样；先用短训练核对结果。

## 备份分别保存什么

| 出口 | 包含 | 不包含 |
|---|---|---|
| 设置中的普通 JSON 备份 | 路线、保留的训练/单轮明细、归档统计与容量信息 | 原始运动文件、语音日志、偏好、进行中恢复点 |
| CSV | 可供表格查看的成绩 | 可直接还原应用的完整数据 |
| 训练分析 JSONL | 对应训练、原始样本、识别、修正、缺段和语音日志（如存在） | 可直接导入恢复的应用备份 |

Android 10+ 可以保存到系统下载目录。更早版本通过系统分享保存到自己的文件位置。分享面板打开不等于目标应用已保存，完成后请检查目标文件确实存在。

训练分析文件可能包含路线和时间信息，不要直接发布到公开 Issue。原始样本约按 10 Hz 留存，历史旧记录可能没有样本。

## 更新

公开版后续更新应使用同一发布签名，直接覆盖安装并保留数据。升级前先导出备份，升级后查看原路线和最近训练。

早期个人内部版使用不同证书。遇到“签名不一致”时停止安装，不要直接卸载。维护者需先核对完整备份、原始运动文件和迁移方案；普通 JSON 备份不覆盖全部应用状态。

目前不提供自动迁移内部版签名或一键回退。降级也可能无法读取新数据，不建议通过卸载重装排障。

## 遇到识别或保存问题

识别不准时，停稳后选择实际楼层再结束。人工确认影响普通累计，不会把这轮自动变成可信的算法学习样本。

若提示保存失败，不要清数据或卸载，保留现场后重试。恢复点用于继续或保存中断训练，不表示原始采样从未中断。

反馈时先提供版本、模式、机型、是否锁屏和复现步骤。不要先发送全量备份。

## 震动与结算

起始楼层在负一楼与一楼之间直接切换，没有 0 层。标定与爬楼时显示步数、频率、估算热量和上升高度。设置 → 声音与提醒可开关震动及结算铃声，可试听楼层震动、预览盖楼效果；预览不保存训练记录。成绩保存成功后播放盖楼结算，点击跳过可提前进入成绩页。
