# 循阶使用指南

本指南对应当前工作树的 **1.1.7 / Android code16 内部候选**。公开下载仍是 **1.1.5 / code14**，详见[公开版说明](RELEASE_1.1.5.md)。教练与七套皮肤属于内部候选，不代表已包含在公开安装包中；当前视觉整改状态见[皮肤复查记录](skins/GRAPHICS_REAUDIT.md)。

底部四个入口分别是训练、教练、记录、设置。训练用于选择楼栋与开始运动；教练用于课程安排和复盘；记录用于查看成绩；设置用于外观、声音、偏好与备份。

## 教练课程（内部候选）

进入底部“教练”，可选择目标体重管理、新手爬楼入门或日常心肺提升。当前公开的 1.1.5-preview.1 安装包尚不包含本节功能。

1. 进入课程，填写真实体重、身高、阶段目标和训练日，确认后生成安排。输入会暂存为本机草稿。
2. 当天打开课程，选已有楼栋或标定新楼栋，完成平地热身后开始。课程沿用楼栋训练和结算流程，按有步伐证据的活动时间累计，可分次完成；漏练无需补量。
3. 结束并保存后填写训练感受。提前结束会保留已完成部分；静止点按确认的楼层不会凭空增加活动时长。中断训练可从训练首页继续，保存失败可重试。
4. 在“记录体重 / 查看趋势”记录实际称重，可按日期修正或删除。体重不从热量推算，近期均重达到目标后可转入维持阶段。
5. 每周复盘完成情况、身体感受和生活习惯。减量只影响尚未开始的后续安排；有不适时暂停。体重短期不变不会自动加量。
6. 教练数据随本机备份导出，导入预览会说明替换或合并；恢复导入前快照可一起撤销教练与楼栋变化。旧备份不含教练数据时，保留本机现有记录。

## 安装和第一次训练

公开安装包从项目 [GitHub Releases](https://github.com/HigloDev/steploop/releases) 下载；先核对版本与发布说明。内部候选使用维护者提供的对应包，不把开发预览图当作公开版本。

1. 首次进入阅读隐私说明与引导。在“训练”选择“在新楼栋开始”，按实际位置设置起始楼层；负一楼与一楼之间没有0层。
2. 点击“开始爬楼”。新楼栋第一轮用于标定，每到一层平台停稳后点“到了一层”，到顶按页面提示确认“到顶了”。保持相同携带方式，并核对实际楼层。
3. 按页面提示返回楼下、休息或开始下一轮。已保存的楼栋可用于后续自动计层；没有气压计、采样中断或识别证据不足时，按提示人工确认，不把估算当作已核准结果。
4. 结束训练使用长按确认，防止误触。保存后查看成绩、核对各轮楼层，必要时修正；新楼栋按结算提示保存，之后可在“我的楼栋”管理名称、重新标定或删除模板。删除模板不会删除历史成绩。
5. 下次可直接选择已保存楼栋开始。首页发现中断训练时，按恢复提示继续或保存；保存失败先重试，避免清数据或卸载。

原有“我的路线”“熟悉路线”和逐层检查不是当前训练入口。旧成绩仍在记录页保留，缺少逐层数据的旧楼栋可重新标定。

首次建议保持屏幕点亮和应用前台。若要尝试锁屏，在设置页检查锁屏持续采集状态，并通过应用入口打开本应用的系统电池设置。返回后会重新读取状态。系统授权并不能保证所有机型都不断采样；先用短训练核对结果。

## 记录与分享

“记录”汇总本周训练，可按完成/中断筛选并搜索记录。点开一条成绩查看详情；需要修正时按页面提示操作。历史旧单轮记录保留兼容查看，不能据此开始旧版路线流程。

首页周卡可分享本周成果，训练成绩可进入分享预览。先检查图中数值和单位，再保存或调用系统分享。切换皮肤会影响新的分享预览；系统分享面板打开并不代表接收应用已经保存成功。

## 皮肤与明暗（内部候选）

设置 → 皮肤与外观，选择钴蓝晴空、荧光夜行、松风山岚、紫电幽光、绯焰流光、晴金跃动或樱粉和弦，再选择浅色、暗色或跟随系统。两项选择独立保存，切换皮肤不会重置明暗模式。训练、楼栋和教练数据不随换肤改变。

保存失败时本次外观可能仍临时显示，按提示重试；冷启动后应恢复成功保存的选择。手机上已安装的上一候选可能仍显示旧名称，名称以实际安装版本为准。系统权限窗口和桌面安装图标不属于应用内即时换肤范围。

## 备份分别保存什么

| 出口 | 包含 | 不包含 |
|---|---|---|
| 设置中的普通 JSON 备份 | 楼栋模板、兼容的旧路线、保留的训练/单轮明细、归档统计与容量信息；内部候选还包含教练课程、称重与复盘 | 原始运动文件、语音日志、声音及外观偏好、进行中恢复点 |
| CSV | 可供表格查看的成绩 | 可直接还原应用的完整数据 |
| 训练分析 JSONL | 对应训练、原始样本、识别、修正、缺段和语音日志（如存在） | 可直接导入恢复的应用备份 |

Android 10+ 可以保存到系统下载目录。更早版本通过系统分享保存到自己的文件位置。分享面板打开不等于目标应用已保存，完成后请检查目标文件确实存在。

训练分析文件可能包含路线和时间信息，不要直接发布到公开 Issue。原始样本最多按10 Hz留存，不会插值补造；历史旧记录可能没有样本。

## 更新

公开版后续更新应使用同一发布签名，直接覆盖安装并保留数据。升级前先导出备份，升级后查看原楼栋和最近训练。

早期个人内部版使用不同证书。遇到“签名不一致”时停止安装，不要直接卸载。维护者需先核对完整备份、原始运动文件和迁移方案；普通 JSON 备份不覆盖全部应用状态。

目前不提供自动迁移内部版签名或一键回退。降级也可能无法读取新数据，不建议通过卸载重装排障。

## 遇到识别或保存问题

识别不准时先停稳，结束并保存训练后，在成绩详情核对和修改对应轮次的楼层。修正会保留记录；人工修改不等于已经验证自动识别准确。

若提示保存失败，不要清数据或卸载，保留现场后重试。恢复点用于继续或保存中断训练，不表示原始采样从未中断。

反馈时先提供版本、模式、机型、是否锁屏和复现步骤。不要先发送全量备份。

## 震动与结算

起始楼层在负一楼与一楼之间直接切换，没有 0 层。标定与爬楼时显示步数、频率、估算热量和上升高度。设置 → 声音与提醒可开关震动及结算铃声，可试听楼层震动、预览盖楼效果；预览不保存训练记录。成绩保存成功后播放盖楼结算，点击跳过可提前进入成绩页。
