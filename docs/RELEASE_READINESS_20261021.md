## 稳定版最小待办

1. **真实运动结果**：固定候选包，在实际楼梯完成首轮标定、重复上行与下行、多轮结束；人工记录实际层数，核对逐轮与累计结果、修正与重启后记录，保留对应脱敏运动证据。
2. **连续记录与日常稳定性**：覆盖亮屏、锁屏、切后台与系统省电情形，检查传感器时间轴是否连续、缺段提示是否准确，并记录较长时长训练的异常及耗电。按目标设备范围补充回归。
3. **正式分发与升级**：使用既有公开发布签名生成 APK，验证旧公开版升级、备份恢复、冷启动与独立运行；上传版本说明、校验值和明确的已知限制，核对匿名下载。个人内部签名安装继续使用匹配证书的升级路径，保留原应用与数据。

核心现场问题若有失败，先修复并重测，再确认稳定版。云同步、社交、排行、iOS 和应用商店上架不列入本次 Android 稳定版的前置条件。
