# 循阶 1.0.7 · Android 公开试用版

本次把使用过程串成一条主线：添加或导入路线 → 熟悉路线 → 检查是否认对 → 开始爬楼 → 查看成绩。

- 首页集中到“我的路线”，减少重复入口；保留自动定位和名称建议。地图不可用时可以手动填写。
- “熟悉路线”先逐层走两遍，每到一层停稳后点一下实际楼层；再分别检查逐层识别和正常完整爬楼。有电梯的路线还需检查电梯上下，以及平地行走和休息。
- 检查没通过就继续保留待完成状态，不会显示已经准备好。原有路线和成绩继续保留，旧路线首次使用新流程时需要重新熟悉。
- 路线可以分享成文件。导入前先看内容，同名路线另存，不覆盖原路线；收到的人还需用自己的手机完成检查。文件不包含个人训练记录或完整原始运动数据。
- 增加步骤切换、到层反馈和完成训练的小动效；跟随系统减少动画的设置。
- 气压变化只辅助判断上行、下行、电梯等趋势，不直接按固定高度换算楼层。

## 安装和更新

下载 `steploop-1.0.7-android.apk`，适用于 Android 7.0+ ARM64 手机，也包含 x86_64。
公开包沿用此前 1.0.5 公开版的发布证书，可覆盖升级。升级前在设置中保存备份，升级后核对路线和记录。
早期个人内部版证书不同，不要为了装公开包而卸载或清除数据；请使用与原版一致的内部升级包。

公开包不含开发者地图凭据；定位和地图名称建议是否可用取决于地图服务配置，手动填写路线仍可使用。
熟悉路线时固定手机携带位置、保持应用前台和屏幕点亮，到平台停稳后再操作。
