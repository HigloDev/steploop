# 循阶 1.0.4 · Android 公开试用候选

此说明随本地候选提供，尚未公开发布。验收进度见 [FIRST_RELEASE.md](FIRST_RELEASE.md)。

## 适用范围

Android 7.0+，ARM64 手机；包内也包含 x86_64 模拟器架构。不是 iOS 安装包。不依赖 Expo Go 或电脑开发服务器。推荐有气压计的手机。

## 可以试用

无地图开练、路线与多轮训练、实际楼层确认、记录和趋势、离线语音反馈、成果动画、海报、备份与 CSV/原始 JSONL 导出。

第一次建议手动模式、固定携带位置、保持前台亮屏。自动/全自动及锁屏能力仍需真实设备验证，不承诺全部机型自动识别准确或后台不断采样。

## 与个人内部版的区别

- 使用专用发布签名；不能直接覆盖旧内部签名版本，不要卸载旧版来强行安装。
- 不嵌入维护者地图凭据，地图选点不可用，可以使用无地图开练。
- 版本 1.0.4 / versionCode 5。UI、识别和训练保存逻辑沿用 R9，本轮主要完成发布资料、版本及源码交付整理。

## 数据范围

训练及旧单轮明细分别保留最近 100 条，更早记录保留汇总。普通备份包含路线、成绩和归档统计；原始传感器文件需另行导出，偏好及进行中的恢复点不在普通备份中。

## 尚未放行的项目

隔离模拟器已通过首次安装、手动 0 层保存和冷重启查看记录，安装包回读哈希一致；483 项自动化、TypeScript 和 Expo Doctor 21/21 通过。

仍待真实多轮训练、语音素材再分发依据及目标 GitHub 仓库确认。模拟器结果不代表手机真实识别或锁屏已通过。最终结果以 FIRST_RELEASE.md 和本地候选核对记录为准。

发布时上传 APK、SHA256SUMS.txt、本说明，并选 Pre-release。不要把 Source code ZIP 当作安装包。反馈通过仓库 Issues，不公开上传完整备份或个人运动原始数据。
