# 循阶 1.1.0：一次标定，自动循环爬楼

## 新流程

1. 首次安装引导说明必需传感器，并提供自检。没有气压计、加速度计或陀螺仪，或无法取得连续有效新数据，不能开始锻炼；历史、海报与备份仍可使用。每次进入训练也重新自检，不能通过跳过引导绕开。
2. 首页点“开始爬楼”，只输入起点楼层，默认 1，允许负数，禁止 0。无需添加路线、熟悉路线或完成多次检查。
3. 标定轮每到一层点大按钮“到了 X 楼”，可撤销误点。标记记录点击时刻、前后各 1 秒的气压高度中位数，以及该层步数、用时和 StairTurnGate 拐弯数。高度异常只提示、不阻塞；约两倍层高的漏点自动拆成两段并标记估算。
4. 坐电梯下行或沿楼梯下楼，自动结束本轮，记录下行开始之前的最高楼层。检测确认有延迟，但成绩结束时刻回溯到下行起点，不把下行的步数与时间计入爬升。
5. 返回楼下，在稳定平台停留至少 3 秒，出现连续步数和高度上升后自动开始下一轮。以本轮平台气压重新归零，累计高度计层，不用速度门槛卡住慢爬。中途平台休息不清空进度。
6. 自动轮继续提供“到了 X 楼”和“纠正当前楼层”，可输入较低或较高的实际楼层。纠正只改变当前轮进度；模板学习只使用这些有采样时刻的纠正锚点。
7. 点“结束训练”后，在同一结果页核对、修改任意一轮。没有每轮结束弹窗。模板自动保存，楼名可在结果页填写，地点可在楼宇模板页补充。下次选择已保存模板，跳过标定。

语音保留已有录音、数字播报、声音偏好与日志；自动轮每次晋层播报累计实际爬升段数。成绩海报、历史、导出备份和 Android 原生后台采样保留。

## 从主流程移除的内容

- 移除训练模式选择、首次开练的携带方式和名称前置问题、路线验证与重新标定入口、训练计划准备入口。
- `Calibrate`、`Validate` 不再注册为主导航页面；旧代码保留。当前源码本来没有独立的 `Familiarize`、`route-preparation`、`motionReference` 模块，未虚构删除文件。
- 新 `ClimbWorkout` 导航指向 `BuildingWorkout.tsx`，使用 `useBuildingWorkout.ts`。原 `ClimbWorkout.tsx`、`useClimbWorkout.ts`、`useClimbRoundSession.ts` 和旧状态机保留供兼容与诊断参考，不参与新训练。
- 新计层不调用 DTW、RouteRecognizer 或 FreeRecognizer，也不查询五轮学习门槛、路线 verified 状态或跨天条件。旧识别器继续服务旧诊断回放。
- 不再向每一个加速度样本附加 `latestPressure`。Android 在 `TYPE_PRESSURE` 事件单独落盘与发送，时间使用 `clockOffsetMs + event.timestamp / 1_000_000`；JS 按气压事件时间去重，Expo SDK 57 的秒级 timestamp 只转换一次到采集时钟。无有效时间戳的气压事件不参与新识别。

## 数据与兼容

- 新成绩、轮次和楼宇模板标记 `recognitionVersion = 'baro-v1'`。`BuildingTemplate` / `BuildingFloor` / `BuildingAnchor` 定义在 `src/core/types.ts`；楼宇模型 `schemaVersion = 1`，存储在既有路线的 `building` 字段。
- 每层保存累计高度 H、层高 h、步数、拐弯数、时长、估算标志和最近最多五份高度证据。未纠正且到达模板顶层的可靠自动轮可学习；高度证据采用接近模板层边界的实际转向位置，避免把提前播报阈值反复回灌成层高。纠正轮只学习纠正点。相邻 h 根据更新后的 H 重新作差。
- 旧路线在使用时转换：优先 `floorHeights`，否则按 `totalAscentM` 均分；没有高度资料则下次逐层标定。不在导入时重算旧成绩。
- 备份版本提升为 3，同时接受 1、2、3。模板与新识别标记随路线/成绩导出。损坏的新模板结构会给出可读错误；旧记录的识别版本、修正链与已保存层数保留。
- 新楼层全部按爬升段数：1→15 为 14；-1→1 为 1；-2→10 为 11。统一楼层索引跳过 0。
- 历史轮次和旧单轮页面直接显示其保存的 `floorsCompleted`，取消旧展示层将历史层数再加一的行为。旧 `motion-v3` / `trusted-v2.1.0` 数据及 `diagnostics:replay` 仍可读。
- 检查点每 5 秒及切轮时保存已完成轮次；恢复从下一轮开始，不声称恢复未持久化半轮的完整传感器状态。保存或后台停止失败时保留重试路径，最终成绩快照在重试期间固定。

## 两处需求取舍

### 无气压计

根据本次后续确认，**无气压计不允许启动锻炼**，不是让用户凭步数和转弯猜电梯。底层仍保留无气压/气压 stale 的“步数 + 拐弯”计层，以支持运行中暂时失去气压的情况。stale 期间不使用旧高度或旧垂直速度作任何判断，也不编造电梯切轮。气压恢复后自动识别继续；始终无法恢复时可以直接结束整次训练，再在总览修改。

无气压的单元测试可显式结束一轮检查结果与时间，这是底层能力测试，不是产品提供的无气压开练路径。

### 热量

原要求的 `机械功 + (MET水平 − 1) × 体重 × 实际上爬小时数` 与“同高度爬得慢不能更多热量”数学上矛盾。采用后者优先：

```
机械功 kcal = 体重 × 9.81 × 爬升高度 / 0.2 / 4184
标准上爬小时数 = 爬升高度 / 0.35 / 3600
新成绩 kcal = 机械功 kcal + (3 − 1) × 体重 × 标准上爬小时数
```

这是标准化运动消耗估算，不是个人代谢实测。相同体重、相同高度，不随速度、休息或电梯时间增加。实际净爬升用时仍单独记录；旧成绩沿用旧热量展示口径。新结果页、海报和训练中的语音里程碑采用高度热量。

## 算法参数

新参数集中在 `src/core/sensor-params.ts` 的 `BARO_V1`。时间单位为毫秒，高度为米，压力为 hPa；下表包含全部新参数。

| 参数 | 值 | 含义 |
| --- | --- | --- |
| staleMs | 2000 | 超过此时长无真实新气压事件，停止使用气压判断 |
| medianMs / averageMs | 1000 / 3000 | 先做 1 秒中位数，再做 3 秒滑动均值 |
| velocityMs | 4000 | 最近平滑高度线性回归斜率的窗口 |
| altitudeScale / altitudeExponent | 44330 / 0.190263 | 国际气压公式 `h = 44330 × (1 − (p/p0)^0.190263)` |
| anchorRadiusMs | 1000 | 点击前后各 1 秒取原始相对高度中位数；通常等后 1 秒到齐再定锚点 |
| minFloorM / maxFloorM | 1.8 / 6 | 标定层高异常提示范围，不阻塞 |
| missedFloorRatioMin / Max | 1.65 / 2.35 | 与中位层高比值在此范围时，自动拆成两层估算 |
| plateauMs / plateauRangeM | 3000 / 0.18 | 返回后无步数、此高度范围内持续稳定，确认平台 |
| startRiseM / startSteps | 0.12 / 3 | 平台后累计上升证据和连续步数，用来启动新轮；不限制之后的计层速度 |
| advanceHeightMargin | 0.3 | 晋层阈值为 `H_k − 0.3 × h_k` |
| advanceStepsRatio | 0.4 | 晋层还需本层至少模板步数的 40%，每次晋层重新累计 |
| fallbackStepsRatio | 0.85 | 气压不可用时需要模板步数的 85%，同时满足模板拐弯数 |
| extraFloorRatio | 0.7 | 超过模板顶层后，再上升 0.7 倍中位层高确认下一层，继续外推 |
| elevatorSpeedMps / elevatorMs / elevatorMaxSteps | 0.8 / 2000 / 2 | 正负垂直速度超阈值持续至少 2 秒、同期步数不超过 2，判电梯；上行禁止计层 |
| descentMs / descentDropM / descentSpeedMps | 2000 / 0.18 / 0.03 | 有步数的持续下降确认，结束时回溯到下降前峰值平台 |
| peakToleranceM | 0.02 | 允许平台上轻微气压抖动，更新峰值平台结束时刻 |
| historyMs | 16000 | 原始气压和启动运动证据保留窗口；容纳慢爬的稀疏脚步 |
| recentStepsMs | 4000 | 近期运动参考窗口，与速度窗口同量级；电梯判断使用独立 2 秒窗 |
| learningRounds | 5 | 每层累计高度保留最近五份证据，取中位数 |
| defaultFloorM / defaultSteps / defaultTurns | 3 / 18 / 2 | 旧路线缺少对应细节时的显式估算默认值，不补造观测锚点 |
| maxWeatherDriftMps | 0.012 | 仅稳定平台估计的缓慢漂移补偿上限；每轮重新估计 |
| driftConsistencyMps | 0.001 | 三个 1 秒子窗与整体漂移斜率的允许差；不一致的噪声不作为长时漂移补偿 |
| activeEnergy | 0.06 | 与步数共同判断有效动作帧；平台静止不计净爬升时长 |
| turningFrameRad / completeTurnRad / turnGapMs | 0.1 / 1.05 / 900 | StairTurnGate 的转向帧、整拐累计角度及转向间隔，沿用旧检测门限 |
| gravity / efficiency / joulesPerKcal | 9.81 / 0.2 / 4184 | 机械功热量换算参数 |
| horizontalMET / calorieReferenceSpeedMps | 3 / 0.35 | 水平项 MET 与标准上爬速度，用于同高度同热量 |
| selfTestMs / selfTestIntervalMs | 3200 / 200 | 开练前实际采样自检时长与目标采样间隔 |

天气补偿只针对可从静止平台观测到的缓慢线性变化。气压、门风和空调变化与真实高度并非在所有环境下都可分离，不能把合成数据通过解释成所有楼宇的精度保证。
