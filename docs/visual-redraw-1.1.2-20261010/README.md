## 视觉规范

- 深色主稿：暖黑底、橙色主操作、白色大字、圆角分组。
- 训练页：最大化楼层数字与留白；底部保留用时、累计层数、轮次与长按结束。
- 结算以总爬升米数为主，各轮层数可修改。
- 图标应使用统一平面图标；生成图片中局部色彩纹理及图标差异不作为实现规范。
- 后续如实施，需以真实设备截图核对尺寸、换行、图标、触控区域与各状态，不能把效果图当成已经实现的画面。
