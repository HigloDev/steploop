# 循阶 · 向上训练

## 设计目标

将专业的运动力量、清晰的信息层次、温和的训练反馈落实到完整爬楼流程。
显示层沿用既有训练、计层、检查点、修正与备份接口。

## 设计依据

- Nike Run Club：围绕开练、运动陪伴、完成反馈安排体验。https://www.nike.com/nrc-app
- Apple Fitness：稳定的进度语言与分层摘要。https://support.apple.com/en-gb/guide/iphone/iph4c34a8a95/27/ios/27
- Strava：可检索的训练记录和可回看的长期趋势。https://support.strava.com/en-us/articles/15402014-viewing-your-activity-history-on-strava
- Garmin Connect：主次信息通过不同密度呈现。https://support.garmin.com/en-GB/?faq=35qboQSvKC2WpKkTaDaRP7
- Gentler Streak：用易懂的文字解释活动记录。https://docs.gentler.app/understanding-your-activity-path/interpret-the-activity-path

## 统一视觉

- `src/theme.ts` 是唯一 token 来源；钴蓝用于操作、进度与关键爬升数据。
- 冷白与深蓝各有完整主题，跟随系统；品牌摘要采用成对深蓝底与浅色文字。
- 页面边距 20 dp，主按钮 52 dp，内容分组以留白、分隔线和 12–20 dp 圆角建立层次。
- 主要数字使用等宽数字；单位与辅助文字使用较小字号及正常字重。
- 界面采用原生文字、真实数据图表、现有品牌标记及 Material 图标。系统状态栏与导航区域由系统绘制。

## 页面与交互

| 页面 | 主信息 | 核心动作与内容 |
|---|---|---|
| 训练首页 | 本周实际爬升及七天记录 | 选常用楼栋 → 开始；新楼栋选择起始楼层；最近一次可直接打开 |
| 运动中 | 当前楼层及真实楼层刻度 | 标定、自动计层、下行、等待各有对应文字；结束与放弃保持长按确认 |
| 训练完成 | 本次爬升与完成情况 | 每趟紧凑记录展示楼层与用时；估算、待确认和修正可辨识并保留修改入口 |
| 记录 | 累计与按日期分组的记录 | 搜索楼栋/日期，筛选状态，切换长期趋势范围，查看同路线最佳 |
| 设置与分享 | 与主流程一致的视觉层次 | 原有设置、导出及分享动作继续可用；海报统一品牌色 |
