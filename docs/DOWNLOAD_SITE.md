# 循阶公开下载网站

公开地址：<https://higlodev.github.io/steploop/>。

GitHub Pages 使用 `main` 分支的 `/docs` 目录。静态 HTML、CSS 与 JavaScript，无须构建、注册、外部字体或分析服务。2026-10-21 按新版应用重新制作，下载指向 `v1.1.5-preview.1`，保持公开试用标记。

## 页面与素材

- `index.html`：新版介绍、原生界面预览、下载、安装升级步骤与常见问题。
- `site.css`：与 App 一致的冷白、深蓝和钴蓝视觉；响应式布局、键盘焦点与减少动画支持。
- `site.js`：首页／训练／结算的六组深浅主题预览、键盘切换、扫码弹窗与复制链接。关闭 JavaScript 后仍可阅读和下载。
- `assets/site115/`：此前隔离原生界面中的合成数据截图；标志复用应用的白色人物轮廓，以 SVG 组合钴蓝底色。二维码继续指向本公开页面。没有使用个人训练截图或备份。
