## 产品与代码主线

目标是把训练入口收敛为一个明确动作：陌生楼直接开始，第一轮人工逐层标定；熟悉的楼栋点选模板直接训练；结束后统一核对和修改各轮成绩。主界面使用橙色品牌色，训练页使用深色背景、大楼层数字和清楚的状态提示。

| 层次 | 文件/目录 | 主要职责 |
| --- | --- | --- |
| 应用入口 | `App.tsx`、`src/navigation/` | 隐私同意、首次引导、训练/记录/设置三个标签及训练与结算页面 |
| 首页 | `src/pages/Home.tsx` | 新楼标定、起始楼层、楼栋模板、本周累计、训练恢复 |
| 训练页面 | `src/pages/Workout.tsx`、`src/components/workout-ui.tsx` | 标定、待起爬、爬升、下行等阶段的操作与展示 |
| 会话连接 | `src/hooks/useFusionWorkout.ts` | 传感器、原生后台服务、识别引擎、语音、触感、恢复点和成绩持久化 |
| 融合引擎 | `src/core/fusion-engine.ts` | 接收样本与时间，维护训练阶段和轮次，判断新鲜/停更气压、步数、转弯与模板逐层特征 |
| 标定与模板 | `src/core/fusion-calibration.ts`、`building-template.ts` | 逐层标记、撤销、模板层高与步数特征、标定质量提示 |
| 结果转换 | `src/core/fusion-workout.ts`、`floors.ts`、`workout-summary.ts` | 转为既有成绩结构，统一爬升段数口径并重算修正后的汇总 |
| 楼栋与恢复 | `src/services/building-storage.ts` | 独立楼栋键、旧路线只读转换、训练恢复点、待命名标定草稿 |
| 历史成绩 | `src/pages/History.tsx`、`Summary.tsx`、`src/services/workout-storage.ts` | 新旧成绩展示、各轮修正、楼栋命名与保存、统计与归档 |
| 分享 | `src/pages/ShareStudio.tsx`、`src/core/share-payload.ts` | 成绩海报、默认隐藏地点与身份相关字段 |
| 原始证据 | `src/services/workout-evidence.ts`、`workout-evidence-store.ts` | 本机分片留存实际样本、间断与事件，JSONL 导出 |
| 原生采样 | `native/android-training/`、`plugins/withAndroidTrainingModule.js`、`src/services/sensor.ts`、`background-training.ts` | Android 前后台采样、样本回放及服务状态 |

`FusionWorkoutEngine` 是训练阶段的唯一来源。页面和 hook 负责展示与连接，不再添加一套平行阶段状态机。恢复点保留模板和已完成轮次；进行中的轮次恢复后需要从楼下重新开始。

训练层数采用爬升段数：1 楼到 15 楼计 14 层。楼层编号跳过 0，地下楼层使用负数。估算轮在结算页提醒核对；热量也是估算值。

楼栋使用 `steploop.buildings.v1`，训练恢复点使用 `steploop.fusionActive.v1`。旧路线只读转换展示，重新标定后创建对应的新模板；隐藏旧路线不会删除其原始数据。

## 本轮实现

### 首页、引导和弹窗

- 引导文案与当前标定、结束、结算流程一致，去掉已经撤下的旧路线操作指引。
- 楼栋管理改为 Expo UI 原生底部弹窗，重命名、重新标定、删除和完成均可见，避免 Android Alert 按钮数量限制。
- 起始楼层、重命名和成绩修改共用 `FlowSheet`，支持滚动内容、输入和键盘；小屏或大字体直接展开，保存按钮可访问。
- 修正原生弹窗中 React Native 子内容没有占满宽度的问题。
- 首页增加读取中、读取失败和重新读取状态。资料未成功读取前禁用启动入口，避免把读取失败显示成“没有楼栋”。
- 有未结束或待保存恢复点时，开始新训练、选楼栋及重新标定都会先提示处理上次训练。
- 重命名拒绝空名称，提交中禁用重复操作，保存失败保留草稿；删除与放弃失败显示可操作的错误。

### 保存与恢复

- 结束训练先冻结结束时间、结算轮次并持久化完成恢复点；成绩、标定草稿或楼栋最近成绩全部保存成功后，再清理恢复点。
- 保存失败进入独立重试页面；重试沿用训练 ID 和结束时间，避免重复成绩与用时增加。
- 只有完成恢复点写入成功，才提供“稍后再存”的返回入口；成绩和恢复点同时写入失败时留在当前页面重试。
- 恢复已结束的训练直接重试保存，不重新启动采样，并保留重新标定目标。
- 恢复点写入串行排队，防止旧写入覆盖结束状态；重复结束共享一次保存。
- 放弃清理失败时保留停止后的结果，进入恢复界面，可先保存再删除。
- 楼栋缓存只在落盘成功后更新；读取与写入失败不再静默吞掉。

### 训练和结算

- 训练主体支持滚动，小屏/大字体缩小数字与标定操作区；底部统计和结束按钮固定保留。
- 阶段说明可以换行，避免逐层标定提示被截断。
- 分离原始数据提示与恢复提示，修复成功写入后仍显示“原始数据保存失败”的误报。
- 结算页提供重新读取、提交状态与重复提交保护；旧识别成绩保留查看方式，避免使用 fusion 修正逻辑改写旧记录。
- 修改层数重算汇总，同时保留该次训练的楼栋名称、关联和其他元数据。删除或重命名模板不会让历史成绩变成“新楼栋”。
- 设置里的普通备份说明明确其范围：旧路线与成绩；当前备份格式尚未包含 fusion 楼栋模板。
