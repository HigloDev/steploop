# 循阶 1.1.3 · 完整浅深主题、楼层震动与周成果分享

2026-10-10，Android 公开试用版（Pre-release）。版本 1.1.3 / versionCode 12，包名 `com.zxn.palou`，支持 Android 7.0 及以上、ARM64 与 x86_64。

## 本版变化

- 全部主要页面、弹层和训练状态采用独立浅色、深色主题。
- 起始楼层跳过 0，负一楼直接切换到一楼；兼容旧模板的无效起始层，不重写历史成绩。
- 新增楼层震动及关键操作反馈，可在设置中开关与试听。
- 重排标定与爬楼布局，减少长屏空档，同时显示步数、楼层频率、估算热量和上升高度。
- 成绩保存成功后播放盖楼动画与原创铃声，支持跳过和减少动态效果；历史查看及预览不会新增记录。
- 点击首页周累计查看高度完成情况与 37 种参照；新增独立周分享页，两种海报可保存、分享及复制文案。

## 试用边界

自动计层仍是试验能力。源码测试与模拟器检查不代表实际爬楼准确率；锁屏连续采样、电梯、音频中断和耗电需要继续现场验证。热量为估算值。山峰高度使用海拔，只作累计爬升对照，不代表实际登顶。公开包不包含维护者地图凭据，地图不可用时可手动填写信息。

通过 GitHub Issues 提供版本、手机型号、Android 版本及复现步骤，请勿公开上传完整个人备份、位置或原始训练日志。
